## 2. GitHub Project Board

Create these columns in GitHub Projects:
- **Backlog** — All tasks to do
- **To Do** — Sprint tasks
- **In Progress** — Currently being worked on
- **Review** — Needs testing/approval
- **Done** — Completed

### Issue Labels
- `frontend` — Website/UI work
- `backend` — API/database work
- `engine` — Local AI engine work
- `bug` — Something broken
- `enhancement` — Feature request
- `docs` — Documentation
- `design` — UI/UX design
- `blocker` — Preventing progress

---

## 3. Sprint Checklist

Each sprint (2 weeks):
- [ ] Sprint planning meeting (30 min)
- [ ] Assign tasks from backlog
- [ ] Daily standup updates (GitHub or WhatsApp)
- [ ] Mid-sprint check-in
- [ ] Sprint review (demo what's built)
- [ ] Retrospective (what went well, what to improve)

---

## 4. Communication Rules

- **GitHub Issues** — For task tracking and bug reports
- **Pull Requests** — One PR per feature, tag the reviewer
- **WhatsApp/Discord** — Daily updates and quick questions
- **Weekly Sync** — Saturday 10AM (30 min video call)
