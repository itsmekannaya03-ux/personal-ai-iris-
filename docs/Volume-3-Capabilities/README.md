# Volume 3 — Capabilities

## Purpose
Define the user-facing capabilities of IGRIS — the skills, plugins, voice, vision, automation, and developer tools that extend what IGRIS can do.

## Documents

| Document | Purpose |
|----------|---------|
| 01-Skill-System | Modular skill architecture and built-in skills |
| 02-Plugin-System | Extensibility through third-party plugins |
| 03-Voice-System | Text-to-speech and speech-to-text capabilities |
| 04-Vision-System | Image recognition and computer vision |
| 05-Browser-Automation | Web browser control and automation |
| 06-Desktop-Automation | Desktop GUI automation |
| 07-Terminal-Control | Terminal command execution |
| 08-Developer-Mode | Developer tools and API access |
