# Coding Standards

## Purpose
Define coding standards for all IGRIS code.

## Standards
- Python: PEP 8, type annotations, Google-style docstrings
- TypeScript: ESLint strict, TypeScript strict mode
- All code: Pre-commit hooks, automated formatting

## Enforcement
Linting in CI. Pre-commit hooks locally.
