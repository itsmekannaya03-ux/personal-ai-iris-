# Module Map

## Purpose
Map all modules and their responsibilities within the IGRIS system.

## Module Tree
```
IGRIS
├── Frontend (Next.js 14)
├── Backend (FastAPI)
│   ├── Authentication
│   ├── Subscriptions
│   ├── Billing
│   ├── Notifications
│   └── Webhooks
├── Engine (FastAPI)
│   ├── Neural Core
│   ├── Memory System
│   ├── PIE
│   └── Models
├── Runtime
├── Security
└── Infrastructure
```

## Acceptance Criteria
Every module has a clear owner and defined interface.
